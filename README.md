Этот репозиторий — мой учебный полигон для отработки продвинутых возможностей **SQL** и **ClickHouse**. Здесь собраны скрипты и примеры, которые я создавал в процессе изучения.

## 📚 Что внутри

*   **Транзакции** — примеры явных (`BEGIN TRANSACTION`) и неявных транзакций.
*   **Индексирование и блокировки** — работа с индексами, исследование поведения блокировок (`Locking.sql`, `Indexing.sql`).
*   **Материализованные представления** — пример создания и использования `MATERIALIZED VIEW`.
*   **Нормализация и временные таблицы** — скрипты по нормализации БД и работе с временными расширениями.
*   **Функции и массивы** — пользовательские функции и работа с массивами (`Functions.sql`, `Massives.sql`).

## 🎯 Цель

Применить теорию на практике: понять, как работают механизмы внутри БД, и подготовить базу для более сложных аналитических задач на ClickHouse.
